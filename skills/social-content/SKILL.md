# Social Content / 社媒内容写作

Accept only an evidence pack. Before drafting, state the target audience, the author's angle, and the intended post format. Separate:

只接受证据包。起草前说明目标受众、作者角度和预期帖子格式，并区分：

- verified facts;
- attributed outside views; and
- the author's analysis.

- 已核验事实；
- 有归属的外部观点；以及
- 作者自己的分析。

Do not add claims beyond the evidence. For a single X post, keep the draft at or below 280 characters. Keep source URLs available for review even when they do not fit in the final post.

For every cited source, provide the direct URL as `[Source: Name](https://...)`; never return `Source: Name` without its URL. If the URL does not fit in the post body, put it in a separate review-sources block beneath the draft.

不得添加证据之外的主张。单条 X 帖子须不超过 280 个字符；即使来源 URL 无法放进最终帖子，也要保留供审核使用。每个引用来源都必须写成 `[Source: 名称](https://...)`，不得只写没有 URL 的 `Source: 名称`。若 URL 放不进帖子正文，将其放在草稿下方单独的审核来源区块。
